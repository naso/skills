# @fabiocv/skills

[![GitHub](https://img.shields.io/badge/GitHub-naso%2Fskills-181717?logo=github)](https://github.com/naso/skills)

Interface, interaction design and UX skills for coding agents. The list is at
[skills.fabio.cv](https://skills.fabio.cv).

```bash
npx @fabiocv/skills
```

It runs the [skills CLI](https://github.com/vercel-labs/skills) on
[naso/skills](https://github.com/naso/skills), and takes its `add` options,
such as `-y` to skip the questions or `--skill <name>` for one skill.
`npx skills update` keeps them current.
